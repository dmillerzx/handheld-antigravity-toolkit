## Part 4: Retroid OS Performance Modes & Telemetry Profiling

### 1. Mode Storage Investigation (Standard vs Performance vs High Performance)
Configuration states were captured to `scratch/perf/` across all three modes:
- `standard_system.txt`, `standard_global.txt`, `standard_secure.txt`, `standard_getprop.txt`
- `perf_system.txt`, `perf_global.txt`, `perf_secure.txt`, `perf_getprop.txt`
- `high_perf_system.txt`, `high_perf_global.txt`, `high_perf_secure.txt`, `high_perf_getprop.txt`

#### Differences Across Modes:
| Subsystem / Property | Standard Mode | Performance Mode | High Performance Mode | Description / Impact |
|---|---|---|---|---|
| **`settings system performance_mode`** | `0` | `1` | `2` | Primary Retroid OS performance profile index. |
| **`settings system fan_mode`** | `0` (or `4` Smart) | `1` (or `4` Smart) | `4` (Smart) | Default fan profile. Switching to Standard drops fan speeds immediately. |
| **`persist.vendor.debug.mode`** | `0` | `1` | `2` | Qualcomm vendor thermal/power HAL mode flag. |
| **CPU Cluster 0 (Silver, 4x Cores)** | 1.17 GHz – 1.42 GHz | 1.17 GHz | 1.17 GHz | Efficiency cluster scaling. |
| **CPU Cluster 1 (Gold, 3x Cores)** | 1.28 GHz (idle) | 2.15 GHz (locked) | 2.15 GHz (locked) | Performance cluster floor frequency. |
| **CPU Cluster 2 (Prime, 1x Core)** | 1.51 GHz (idle) | 2.84 GHz (boost) | 2.84 GHz (locked boost) | Kyro 585 Prime core frequency. |
| **GPU Clock (`kgsl-3d0/gpuclk`)** | 305 MHz (idle) | 305 MHz – 587 MHz | 587 MHz – 670 MHz | Adreno 650 dynamic scaling range. |

#### Retroid OS System Components Identified:
- `com.rp.settings`: Hosts `com.ro.settings.service.SecondaryPowerTileService` (Quick Settings performance mode tile) and `com.ro.settings.activity.fan.FanTempControlCurveConfigActivity` (active cooling thermal curves).
- `com.rp.gameassistant`: Hosts `com.ro.gameassistant.service.ForegroundAppMonitorV4Service` (accessibility foreground application monitor) and `FloatingWindowTileService`.

### 2. Auto-Mode Feasibility Analysis
- **Live Shell Command Test**:
  Executed `settings put system performance_mode 0`, `settings put system performance_mode 1`, and `settings put system performance_mode 2` as the shell user via ADB.
- **Results**:
  - The Retroid OS Settings ContentObserver immediately intercepted the change without requiring a reboot or system service restart.
  - Underlying CPU policy frequencies and `persist.vendor.debug.mode` transitioned instantaneously.
  - The Quick Settings tile icon and label updated in real time on the device screen (verified live by user).
- **Auto-Switching Architecture (Recommendation)**:
  An automation utility (e.g. MacroDroid or Tasker) can manage performance modes per application without root:
  1. Grant permission via ADB:
     ```bash
     adb shell pm grant <app.package.name> android.permission.WRITE_SECURE_SETTINGS
     ```
  2. Rule:
     - **Trigger**: App Launched / In Foreground:
       - Packages: `com.sunjaycy.goldeneye`, `com.armsx2`, `org.dolphinemu.dolphinemu`, `com.droiddeck.launcher`, `xyz.aethersx2.android`
       - **Action**: `System Setting [system] performance_mode = 2` (High Performance) & `fan_mode = 4` (Smart Fan).
     - **Trigger**: App Closed / Exit:
       - **Action**: `System Setting [system] performance_mode = 0` (Standard) & `fan_mode = 4` (Smart Fan).
  - **Benefit**: Eliminates unnecessary fan noise and high battery drain during homescreen navigation, reading, or 2D retro gaming, while automatically unlocking full Snapdragon 865 clocks for demanding 3D titles and PC translation.

- **Diagnostic Criteria**:
