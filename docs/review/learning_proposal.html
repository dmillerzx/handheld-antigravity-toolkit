1. Root Cause & Technical Discovery Summary

A. Perfect Dark Native Android Port (XBLA "Duty Calls" Twin-Stick Aim)

Reverse-engineering libpd.so revealed the exact reasons why the native port felt clunky out-of-the-box and why switching to 1.2 Solitaire broke analog controls:

  • StickCButtons = 1 (Default Trap): Quantizes the right analog stick into 4-way discrete digital pulses with a hard threshold (0x4000), completely ignoring analog pitch/yaw look values. Setting StickCButtons = 0 is required for raw 360° analog input.
  • Control Style 8 ("Ext") Invariant: In bmoveProcessInput, analog look processing is locked behind cmp w20, #8. Switching to 1.2 Solitaire sets w20 = 1, bypassing the modern analog aim routine entirely and falling back to digital C-button movement.
  • MouseAimMode = 1 (Center Reticle Lock): N64 floating cursor lets the crosshair drift in an on-screen box before panning the camera. Setting MouseAimMode = 1 locks the crosshair dead-center for instant, modern FPS camera pan.
  • Lookspring OFF: In-game Lookspring must be disabled to prevent the camera from automatically pitching down to level whenever walking forward.
  • Action Bindings: CK_8000 is the port's internal bind for Cycle Crouch [+] (mapped to B and R3), X_BUTTON for dedicated reload, and Y_BUTTON for weapon cycle.

B. Clean ROM Staging & Compression Invariants

Analysis of community-distributed N64 ROM hacks (e.g. Super Smash Bros. Remix) uncovered critical handheld emulator incompatibilities with raw .7z archives:

  • Nested Directories: Subfolders inside .7z archives (e.g., Super Smash Bros (Remix v2.0.1)/...) prevent emulators from identifying the .z64 binary.
  • Standalone Emulators: Mupen64Plus FZ does not support .7z archives.
  • RetroArch Cache Lag: RetroArch decompresses .7z to a temporary cache directory before launching, causing severe launch pauses on 64MB expanded ROMs.
  • The Standard: Repack as a clean Deflate .zip (level 9) named <Title>.n64.zip with exactly one .z64 at the archive root.

# rom-and-port-staging Skill

## 1. N64 ROM Packaging Pipeline
- Extract community .7z into temporary scratch directory.
- Verify internal structure; strip nested directories and documentation files (.txt).
- Repack using Python zipfile with ZIP_DEFLATED and compresslevel=9.
- Name as <Game Title>.n64.zip.
- Push to canonical MicroSD: /storage/<SD_ID>/ROMs/n64/.
- Verify archive integrity on device via: adb shell "unzip -t '<path>'".

## 2. Native Port Modern Twin-Stick Architecture (Perfect Dark)
- Always enforce StickCButtons=0 in [Input.Player1].
- Set Game.Player1.MouseAimMode=1 and CrosshairSway=0.
- Verify in-game Control Style is set to "Ext" (Mode 8).
