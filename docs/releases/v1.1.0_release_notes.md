# Retroid Pocket 5 Master Provisioning Suite (v1.1.0)

A comprehensive zero-touch ADB provisioning suite, hardware optimization engine, and ROM standard alignment pipeline for the **Retroid Pocket 5** (Qualcomm Snapdragon 865 / Android 13).

---

### Highlights in v1.1.0

#### 1. Native Android Handheld Ports (19 Verified Titles)
- **Diddy Kong Racing Recompiled (DKR-R)**: Resolved Qualcomm Adreno 650 null pipeline crash (`plume_vulkan.cpp`), integrated AdrenoTools Turnip driver loader (`TurnipZ-0.3.0.zip`), and calibrated 60 FPS widescreen presentation.
- **Banjo-Kazooie Recompiled (Banjo Recomp v0.1.6)**: Fixed Adreno 650 RT64 startup crash, added automatic ROM ZIP extraction, implemented authentic v1.0 (Rev 0) version inspection & warning dialogs, added zero-touch auto-hydration from MicroSD/internal storage, and bound dual-trigger (`ZL + L1`) crouch.
- **Paper Mario 64 (PaperBoat)**: Updated to PR #275 test build resolving 64-bit ARM tagged pointer (TBI) texture corruption, staged authentic `pm64.o2r`, and suppressed touch overlays.
- **Super Mario 64 (SM64 ALO)**: Built touchless 60 FPS widescreen binary with BetterCamera analog controls and multi-bound crouch.
- **Sonic Mania Plus**: Native 1080p 60 FPS RSDKv5 engine deployment with auto-staged data.
- **Perfect Dark**: XBLA "Duty Calls" twin-stick control scheme (`StickCButtons=0` raw 360° analog look, Left Stick move, Right Stick aim, instant reload).
- **CannonBall OutRun Arcade**: Native Libretro 60 FPS 16:9 engine eliminating PC translation overhead.
- **PokeMMO & Apotris**: Verified 60 FPS native ports with custom ES-DE `.app` dispatchers.

#### 2. Retro Game Corps (RGC) ROM Standards Alignment
- **Nintendo 64 (N64)**: Remediated all 294 titles from `.zip` archives into pure, uncompressed Big-Endian `.z64` format per Russ's Retro Game Corps standards, eliminating on-the-fly decompression stalls in standalone emulators.
- **Nintendo DS (NDS)**: Purged redundant `.zip` duplicates to preserve single uncompressed `.nds` containers.
- **Original Xbox (hakuX)**: Integrated sector-aligned trimmed XDVDFS `.iso` images generated via `extract-xiso -c` (78.1% space savings, direct DMA streaming, zero CPU decompression overhead).

#### 3. Original Xbox Handheld Emulation (hakuX)
- Integrated standalone `hakuX` (`com.rfandango.haku_x`) with SAF intent dispatch (`%DATA%=%ROMSAF%`).
- Calibrated emulated EEPROM screen formatting and aspect ratio handling.
- Automated tracking and updates via Obtainium.

#### 4. Standalone 3D Emulation & Widescreen Engine
- **Dolphin (GameCube & Wii)**: Staged 550 GameCube per-game profiles in `patches/gcn/` (323 verified Gecko widescreen codes + 225 native 16:9 configs). Enforced analog trigger bindings (L=`Axis 22+`, R=`Axis 23+`) and Mario Kart Wii Classic Controller profile.
- **PS2 (ARM SX2 / NetherSX2)**: Deployed 4,700+ `.pnach` master widescreen cheats. ARM SX2 configured with 2.0x 1080p Vulkan, 16:9 Overscan crop, and Disable Readbacks.
- **Hall Effect Stick Resting Deadbands**: Applied calibrated 10% deadbands across Dolphin, ARM SX2, and RetroArch to eliminate magnetic drift.

#### 5. Ultra-Low-Latency 2D RetroArch Engine
- 48ms OpenSLES audio latency with Vulkan video backend and Run-Ahead frame prediction.
- Genesis Model 1 low-pass filter (range 60, YM2612 MAME).
- Super Nintendo Gaussian audio interpolation (Snes9x).
- Game Boy Advance 5.5kHz IIR low-pass DSP filter (`gba_lowpass.dsp`) + `mGBA.slangp` LCD grid shader.

#### 6. Mesa Turnip Adreno 650 GPU Driver Hierarchy
- Staged gold-standard Turnip driver collection to `/sdcard/Download/drivers/`:
  - `turnip_v24.3.0_R9v2.zip` (K11MCH1)
  - `TurnipZ-0.3.0.zip` (AlexSanz0902 SD865 build)
  - `Turnip-24.1.0.adpkg_R18.a6xx.zip`
- Pre-configured DroidDeck Steam launcher with FSR 1080p and Turnip integration.

#### 7. Retroid OS System & Hardware Automation
- Android 13 Phantom Process Killer unlock (`max_phantom_processes 2147483647`).
- Enforced regular Performance mode default with active cooling (`fan_mode 4`).
