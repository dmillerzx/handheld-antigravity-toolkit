# DKR-R v1.0.11 Android Community Preview

### Overview
This release restores active Android support for **Diddy Kong Racing Recompiled (DKR-R)** following upstream's discontinuation of Android support in [ThatGuyMcd/DKR-R#70](https://github.com/ThatGuyMcd/DKR-R/issues/70). Built against the complete upstream **v1.0.11** code line including all recent rendering, vehicle, and stability enhancements.

---

### Highlights & Fixes

1. **Adreno 650 (Qualcomm Snapdragon 865) Crash-on-Launch Fix**
   - Resolves the hard `SIGSEGV` crash in `vulkan.adreno.so` inside `qglinternal::vkCmdBindPipeline`.
   - Plume now guards pipeline handles so failed shader links never pass a null handle to Vulkan command buffers, allowing devices like the **Retroid Pocket 5**, **Ayn Odin**, and **Galaxy S20** series to boot and play smoothly.

2. **Full N64 US Rev A (v1.1) ROM Support**
   - Added automated multi-revision handling for US Rev A (`dkr.us.v80` / `6d96743d46f8c0cd0edb0ec5600b003c89b93755`) alongside original US v1.0 (`dkr.us.v77`).

3. **Startup Health Dialog Guard**
   - Clears and guards against initial modal startup crashes on clean installations.

4. **Handheld Controller & Presentation Tuning**
   - Fully calibrated for modern handheld gaming layouts (Retroid Pocket 5, Ayn, etc.):
     - **Button A**: Gas / Accelerate / Confirm
     - **Button X / B**: Brake / Reverse / Cancel
     - **Right Trigger (RT)**: Modern racing trigger acceleration
     - **Left Trigger (LT)**: Item / Weapon fire
     - **Right Bumper (RB)**: Hop / Drift
     - **Left Bumper (LB)**: Map / Horn
   - Reduced stick deadzones from 23.95% down to 6.0% with linear 1:1 steering curves and 0.20 hair-trigger engagement.
   - Interpolated 60 FPS presentation at native 1080p.

5. **Upstream v1.0.11 Upgrades**
   - Includes all 22 post-1.0.10 upstream enhancements: memory stability primary heap, render stability liquid replacement gate, water residency in RT64, vehicle original texture restoration, and netplay performance improvements.

---

### Installation
1. Download and install `DKR-R-1.0.11-Android-arm64-preview.apk`.
2. Grant storage permissions when prompted.
3. On first launch, provide an authentic US v1.0 or US Rev A Diddy Kong Racing ROM (`.z64`).
4. Select **Play Offline - Diddy Kong Racing** from the launcher.
